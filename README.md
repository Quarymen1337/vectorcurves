# Проект генерации структур на основе кривых

# Струкутра 
1. src - содержит основные функции и методы для работы с моделью
   1. data - скрипты для работой над датасетом и его загрузкой
   2. features - скрипты для работы над признаками белков и их кривых
   3. metrics - функции потерь и метрик для обучения модели
   4. models - классы архитектур моделей(VAE, AE)
   5. pdb - скрипты для обработки pdb файлов
   6. preprocessing - скрипты для создания 3D сплайнов, а также обработки атомных последовательностей и создание кривых на основе CA атомов
   7. utils - утилиты для загрузки конфигов, а также различные фильтрации
   8. visualization - непосредственно функции для визуалиации
2. tests - содержит основные тесты для проверки работы модели и кода.
3. notebooks - содержит ноутбуки с анализом данных и другими экспериментами
4. models - каталог для сохранения моделей
5. configs - католог для хранения конфигурационных файлов
6. data - каталог для данных обучения и валидации

# Установка и запуск 
   Необходимые программы:
   python 3.11
   
   После клонирования папки с проектом:
   cd VectorAtomCurves
   
   Для запуска проекта в ОС Linux
   1. Создание виртуального окружения:
      python3 -m venv venv
   2. Активация окружения:
      source venv/bin/activate
   3. Устновка зависимостей 
       pip install -r requirements.txt
   4. Установить нужные параметры в configs/config.yaml
   5. Запустить python RUN_AE.py
